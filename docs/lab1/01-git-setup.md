# Настройка Git

Проверка установленной версии:

```bash
git --version
```

Если Git не установлен, установочные файлы доступны на
[git-scm.com](https://git-scm.com/downloads).

Настройка автора для текущего репозитория:

```bash
git config --local user.name "RobertoKarlol"
git config --local user.email "joppoj8@gmail.com"
```

Эти значения записываются в `.git/config` и используются в новых
коммитах. Они не являются электронной подписью и не настраивают вход
в GitHub. Ключ `--global` задаёт значения по умолчанию для всех
репозиториев пользователя; локальные настройки имеют приоритет.

Проверка настроек:

```bash
git config --local --get user.name
git config --local --get user.email
git log -1 --format="%an <%ae>"
```

Первые две команды показывают текущую настройку, последняя — автора
последнего коммита. Изменение настройки не меняет уже созданные коммиты.
